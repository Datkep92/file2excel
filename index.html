📄 File2Excel

Chuyển đổi ảnh / PDF / Excel sang Excel — mọi xử lý diễn ra ngay trên trình duyệt của bạn.

📥
Kéo thả file vào đây hoặc bấm để chọn file

Hỗ trợ: PDF, ảnh (JPG/PNG/…), Excel (XLSX/XLS/CSV)

⚙️ Cấu hình OCR (dành cho ảnh)
Endpoint nhận POST, body JSON: { imageBase64, mimeType }, trả về { text } hoặc { lines: [...] }.
🔒 100% xử lý tại máy bạn — Excel/PDF/CSV không gửi đi đâu. Riêng với ảnh, nội dung được gửi tới OCR API bạn tự cấu hình ở trên.
